# ig — Instagram хөгжүүлэх төсөл

Хувь хүн / брендийн Instagram-ийг хөгжүүлэхэд туслах төсөл. Гурван үндсэн хэсэгтэй.

## 📁 Бүтэц

| Хавтас | Зориулалт |
|--------|-----------|
| `website/` | **Link-in-bio вэбсайт** — Instagram bio-д тавих, бүх холбоосыг нэг газар |
| `tools/` | **Хэрэгслүүд** — контент төлөвлөгч (пост хуваарь, санаа) |
| `content/` | **Контент** — зураг, видео хадгалах газар |

## 🌐 Вэбсайт

`website/index.html` файлыг браузераар нээж харна. Тохируулахдаа:
- Нэр, тайлбараа `index.html` дотор бичнэ
- Холбоосуудаа (Instagram, YouTube гэх мэт) оруулна
- Өнгийг `style.css` дээрх `--brand` утгаар солино

GitHub Pages-ээр үнэгүй интернэтэд нийтэлж болно.

## 🛠 Контент төлөвлөгч

```bash
python3 tools/content_planner.py add "Постын санаа" 2026-06-25   # санаа нэмэх
python3 tools/content_planner.py list                            # хуваарь харах
python3 tools/content_planner.py done 1                          # дууссан гэж тэмдэглэх
python3 tools/content_planner.py remove 1                        # устгах
```

## 🎨 Контент үүсгэх

AI-аар зураг/видео үүсгэж `content/` хавтаст хадгална.
