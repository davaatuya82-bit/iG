# iG — Даваа · Өөрийгөө хайрлахуй

Энэ бол **нээлттэй (public)** repo. Дотор нь зөвхөн **олонд харагдахад зориулсан** зүйлс байна:
вэбсайт, нийтлэх зурагнууд, тусламжийн хэрэгслүүд.

> 🔒 **Хувийн / нууц зүйлс** энд биш, тусдаа **`Davaa-private`** (хаалттай) repo-д хадгалагдана.

---

## 🗺️ Газрын зураг — юу хаана байна вэ

| Хавтас | Юу байгаа | Тайлбар |
|--------|-----------|---------|
| 🌐 `website/` | Вэбсайтын файлууд | Интернэтэд нийтлэгддэг **амьд сайт** |
| 🖼️ `images/` | Зурагнууд | Facebook/Instagram-д тавих зураг, профайл зураг |
| 🛠️ `tools/` | Тусламжийн программ | Контент төлөвлөгч, зураг үүсгэгч |
| ⚙️ `.github/` | Автомат тохиргоо | Вэбсайтыг автоматаар нийтлэх (битгий устга) |
